# bonobo-visual-affordance

Research compendium for “Perceptual discrimination and visual affordance of stone artifacts in Bonobos (Pan paniscus): Implications for the origin of lithic technology”





\## File Structure



The repository is organized into three main directories: analysis, data, and output.





\### script



\* `Script.R` ... This is the R script generating the main results and figures of this paper.





\### data



\* `core\_vs\_flake\_training.csv`... This file documents the choices of bonobo in each single trials, where f means they chose a flake and c means they chose a nodule.



\* `flake data.csv`... This csv file documents the metrics of flakes used in the experiment.



\* `nodule data.csv`... This csv file combines the metrics of nodules used in the experiment.







\### output







\* `Fig.1.bonobo\_kinship\_pedigree.png` ... This is Fig.1 in the manuscript.



\* `Fig.2.png` ... This is Fig.2 in the manuscript.



\* `Fig.3.png` ... This is Fig.3 in the manuscript.



\* `Table\_1\_metrics.csv` ... This is Table 1 in the manuscript.



\* `Table\_2\_individual\_learning\_models.csv` ... This is Table 2 in the manuscript.
